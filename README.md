# Landing page de guia gratuito

Página React com captura demonstrativa de nome e e-mail para um guia gratuito.

## Recursos

Formulário com validação de preenchimento e notificação visual.

## Tecnologias

React, JavaScript e Vite. Consulte package.json para as dependências e versões declaradas.

## Executar localmente

Use Node.js e npm compatíveis com as dependências declaradas:

```sh
git clone https://github.com/Felipegaldinos/landingpage-celular.git
cd landingpage-celular
npm install
npm run dev
```

Abra o endereço exibido no terminal. `npm run build` gera a versão de produção. `npm run preview` permite visualizar esse build.

## Onde começar no código

- `src/App.jsx` — ponto de entrada para entender o projeto.

## Estado atual

Apesar do nome do repositório, o App.jsx analisado apresenta um guia, não um catálogo de celulares. A confirmação não envia e-mail. Existe também script.js com outra implementação de formulário; a entrada React está em src/main.jsx.
